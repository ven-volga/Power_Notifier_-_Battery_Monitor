# ESP8266 Power Notifier & Battery Monitor

Автономний монітор системи резервного живлення на базі **ESP8266 (Wemos D1 mini)** з вимірюванням параметрів через **INA226**, апаратним детектором наявності мережі 230V, локальним UI (дисплей LCD1602 + енкодер) та інтеграцією з Telegram.

Проєкт розроблений для контролю стану акумуляторної збірки (наприклад, LiFePO4 12V 100Ah) під час блекаутів, з урахуванням компенсації просадки напруги під великим навантаженням (інвертор) та енергоефективним режимом роботи Wi-Fi.

---

## 🚀 Основні можливості

* **Точний моніторинг (INA226 + шунт 200А/75мВ):** Вимірювання напруги, струму заряду/розряду, потужності та розрахунок рівня заряду (SOC).
* **Компенсація просадки (IR Drop):** Алгоритм усуває фальшиві спрацьовування захисту та падіння SOC в 0% під час потужного навантаження (наприклад, інвертор на 1.2 кВт).
* **Детекція 230V AC:** Оптична розв'язка (PC817) для миттєвого відстеження зникнення та появи електромережі з програмним дебаунсом.
* **Telegram-сповіщення та управління:** 
  * Сповіщення про зникнення мережі (звіт про попередню сесію зарядки та SOC).
  * Сповіщення про появу мережі (звіт про витрачену енергію за час блекауту та пікову потужність).
  * Команда `/status` для запиту актуальних параметрів у будь-який момент.
* **Енергозбереження Wi-Fi:** Wi-Fi увімкнено лише під час відправки подій або раз на $N$ хвилин для перевірки команд бота. В інший час радіомодуль вимкнений (`WIFI_OFF`).
* **Локальний інтерфейс:** LCD1602 (I2C), енкодер з кнопкою для перемикання сторінок, заглушення тривог та вибору типу акумулятора (LiFePO4, Lead-Acid, GEL).
* **Нічний режим:** Автоматичне вимкнення звукових сигналів зумера в нічний час (23:00 – 07:00).

### Підключення пінів (Wemos D1 mini):
* **I2C (LCD1602):** SCL $\rightarrow$ D1 (GPIO5), SDA $\rightarrow$ D2 (GPIO4)
* **AC Detect (Opto PC817):** Вихід $\rightarrow$ D7 (GPIO13) (LOW = наявність мережі)
* **Buzzer (Active 3V):** Керування $\rightarrow$ D0 (GPIO16)
* **Encoder:** 
  * A $\rightarrow$ D6 (GPIO12)
  * B $\rightarrow$ D5 (GPIO14)
  * Button $\rightarrow$ RX (GPIO3)
* **INA226 (I2C):** Використовує ті ж самі лінії I2C (D1/D2), адреса за замовчуванням `0x44`.

## 🛠 Компоненти

1. **Мікроконтроллер:** Wemos D1 mini (ESP8266).
2. **Датчик струму/напруги:** INA226 + зовнішній шунт 200А / 75мВ ($R = 0.000375\,\Omega$).
3. **Детектор 230V:** Оптопара PC817, резистори $56\,\text{кОм } 1\text{W}$ (2 шт.), варистор 14D471K, діод 1N4007, запобіжник 250mA.
4. **Інтерфейс:** Дисплей LCD1602 з I2C-модулем, енкодер (з кнопкою), активний зумер 3V.
5. **Живлення:** DC-DC понижуючий перетворювач для живлення ESP8266 від акумулятора 12V.

## 📥 Встановлення та налаштування

1. **Встановіть Arduino IDE** та додайте підтримку плат ESP8266.
2. Встановіть необхідні бібліотеки через менеджер бібліотек:
   * `LiquidCrystal_I2C`
   * `ArduinoJson` (версія 6.x)
3. Клонуйте репозиторій або завантажте файл `.ino`.
4. У коді програми знайдіть блок налаштувань користувача та введіть свої дані:
   ```cpp
   const char* WIFI_SSID = "YOUR_WIFI_NAME";
   const char* WIFI_PASS = "YOUR_WIFI_PASS";
   const char* TG_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN";
   const char* TG_CHAT_ID = "YOUR_CHAT_ID";
   ```
5. Підключіть ESP8266 до ПК через USB, оберіть плату **"LOLIN(WEMOS) D1 R2 & mini"** та завантажте скетч.
